Zásady ochrany soukromí / Privacy Policy

Platné od 17. 11. 2026

Jaká data nástroj zpracovává

Jen přístupové tokeny k autorovým vlastním účtům na Instagramu a TikToku a základní identifikátor účtu (open ID / ID účtu). Tokeny slouží výhradně k nahrávání autorových videí.

Jak jsou data uložena

Tokeny jsou uloženy šifrovaně v GitHub Actions Secrets soukromého repozitáře autora. Nejsou sdíleny s nikým dalším ani prodávány.

Data jiných osob

Nástroj nesbírá žádná data diváků ani jiných uživatelů platforem.

Smazání

Autor může přístup kdykoli zrušit v nastavení Instagramu nebo TikToku a smazat uložené tokeny.

English summary

The tool processes only the access tokens and account identifier of the author's own Instagram and TikTok accounts, used solely to upload the author's videos. Tokens are stored encrypted in GitHub Actions secrets of the author's private repository, never shared or sold. No viewer or third-party data is collected. Access can be revoked at any time in the platform settings.
